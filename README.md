# Pomodoro Timer

A simple Pomodoro timer built with Python and Tkinter.

## Features

- 25-minute work sessions
- 5-minute short breaks
- 15-minute long breaks
- Long break after every 4 Pomodoros
- Start button
- Pause button
- Reset button
- Skip session button
- Completed Pomodoro counter
- Desktop notifications using Tkinter message boxes
- No external Python packages required

## Requirements

Python 3.x

Tkinter is included with most Python installations.
